## 3) 前端主题切换链路（已对齐）

1. 主题按钮定义于 `GameHeader.vue` 的 `themeColors`。
2. 点击后触发 `onThemeClick`，调用 `applyTheme`。
3. `applyTheme` 在 `document.documentElement` 上切换 `html.red/green/cyan/blue/brown` 类，并写入 `localStorage` 键 `bw-member-active-theme-name`。
4. `style.css` 通过 `html.<theme>` 覆盖 CSS 变量。
5. `GameHome.vue`、`MemberSidebar.vue`、`NoticeDialog.vue` 等组件通过 `var(--bw-*) / var(--el-*)` 消费变量，完成联动换肤。

## 4) 校验结果

- 核心变量校验：5个主题 × 11个关键变量（`--bw-header-color`、`--bw-default-color`、`--bw-linear-bg`、`--bw-form-item-label-bg-color`、`--bw-table-header-bg-color`、`--bw-bg-3`、`--bw-bg-4`、`--bw-border-color`、`--el-color-primary`、`--el-border-color`、`--el-color-primary-light-9`）全部一致。
- 二级导航联动：5个主题下均满足
  - 激活项（两面盘）=`rgb(255, 0, 0)`
  - 未激活项（1-3球）=各主题 `--bw-default-color`
  - 分隔符 `|` = `rgb(255, 255, 255)`
- 结论：当前前端主题切换与抓取到的五主题标准值一致，无变量级偏差。
